# Hashar sarguzashti

9-sinf ona tili darsidagi “Hashar” hikoyasi uchun sinf bilan birga boshqariladigan interaktiv dars-o‘yin.

## Ishga tushirish

`index.html` faylini ikki marta bosing yoki papkani istalgan statik hostingga joylang. GitHub Pages uchun papka ichidagi barcha fayllarni repozitoriy ildiziga yuklash kifoya; build jarayoni talab qilinmaydi.

## Boshqaruv

- `→` yoki `Space` — keyingi qadam
- `←` — oldingi qadam
- `F` — to‘liq ekran
- `M` — ovozni yoqish/o‘chirish
- `?` yordam oynasidan dars jarayonini qayta boshlash mumkin

O‘yin natijalari brauzerning mahalliy xotirasida saqlanadi va tashqi serverga yuborilmaydi.
